# Oasis React - Modern Web Application

A modern web application built with React, featuring client-side rendering, responsive design, and a seamless user experience with modern React patterns and hooks.

> **Note:** This is a learning project focused on React fundamentals, component architecture, and client-side rendering patterns. For the Next.js version with server-side rendering, see [oasis-next-js](https://github.com/gam1dov/oasis-next-js).

## 🛠️ Tech Stack

- **Framework:** React 18
- **Language:** JavaScript / TypeScript (adjust as needed)
- **Styling:** TailwindCSS (adjust as needed)
- **UI Components:** (Shadcn/UI / DaisyUI )
- **Routing:** React Router v6
- **State Management:** (React Context / Redux )
- **Build Tool:** Vite

## ✨ Features

### 🎨 User Interface
- 📱 **Responsive Design** - Mobile-first approach with TailwindCSS
- 🧭 **Client-Side Navigation** - Fast page transitions with React Router
- ⚡ **Optimized Performance** - Code splitting and lazy loading with React.lazy
- 🎯 **Modern Components** - Functional components with hooks

### 🔄 State Management
- 📦 **Global State** - Centralized state management
- 🎣 **Custom Hooks** - Reusable logic extraction
- 💾 **Local Persistence** - Data saved in localStorage 
- 🌐 **API Integration** - Data fetching with error handling

### 🧩 Component Architecture
- 📁 **Modular Structure** - Clear separation of concerns
- ♻️ **Reusable Components** - DRY principle applied
- 🎨 **Styled Components** - Modern styling approach
- 🧪 **Props & State** - Proper data flow management
